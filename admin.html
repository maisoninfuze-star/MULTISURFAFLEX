Demandes de soumission

Cette page lit les demandes directement dans votre compte GoHighLevel. Elle ne dépend pas des courriels — vous verrez chaque demande, même quand les courriels ne passent pas.

  1. Dans GoHighLevel : Settings → Private Integrations → Create new Integration
  2. Nommez-la « Site web — lecture des demandes »
  3. Cochez uniquement contacts.readonly — lecture seule, rien d’autre
  4. Copiez le jeton (il ne s’affiche qu’une seule fois) et collez-le ici

Le jeton reste dans ce navigateur seulement (localStorage). Il n’est envoyé qu’à GoHighLevel, jamais ailleurs. Sur un ordinateur partagé, utilisez « Oublier le jeton » en partant.
